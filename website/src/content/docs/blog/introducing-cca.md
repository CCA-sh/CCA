cca is a Python-native coding agent: 33 available built-in tools, one pip install,
and a codebase small enough to read in an afternoon.

It is built on two convictions. First, a coding agent should be good
enough to be your default: file editing, search, shell, web access, and
agent orchestration work out of the box. Second, it should be simple
enough to be your research substrate: every session produces a structured
trace you can inspect, replay, and train on.

Read the [documentation](/CCA/docs/configuration/) to get
started, or browse the [source](https://github.com/CCA-sh/CCA).
